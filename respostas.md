# Respostas das atividades

## Atividade 1
**Resposta:** O arquivo index vai ser o responsavel pela estrutura do site/pagina. Ja o style.css sera responsavel pela aparencia e pelo layout

## Atividade 2
**Resposta:** `<!DOCTYPE html>` deve aparecer no início

## Atividade 3
**Resposta:** `<title>` deve ser utilizada para definir o título da aba do navegador

## Atividade 4
**Resposta:** `<h1>` representa o título principal e `<p>` representa um parágrafo

## Atividade 5
**Resposta:** `<section>` deve ser utilizado para representar uma seção de conteudo

## Atividade 6
**Resposta:** `<nav>` deve ser utilizado para agrupar links de navegação. href da tag `<a>` define o destino do link

## Atividade 7
**Resposta:** id tem que ser utilizado para identificar uma seção. Para apontar para a seção sobre, deve ser escrito como href="#sobre"

## Atividade 8
**Resposta:** A tag `<img>` é usada para inserir uma imagem, src define o caminho do arquivo da imagem

## Atividade 9
**Resposta:** `<figure>` (para agrupar) e `<figcaption>` (para a legenda) devem ser utilizados

## Atividade 10
**Resposta:** href é usado para definir o endereço de destino de um link

## Atividade 11
**Resposta:** Um link interno direciona para o próprio projeto, enquanto um link externo direciona para um endereço fora do projeto

## Atividade 12
**Resposta:** A tag ``<table>`` representa a tabela, ``<tr>`` representa uma linha, ``<th>`` representa uma célula de cabeçalho e ``<td>`` representa uma célula comum de dados

## Atividade 13
**Resposta:** mailto: deve ser utilizado antes do e-mail no href (ex: href="mailto:contato@exemplo.com")

## Atividade 14
**Resposta:** ``<footer>`` deve ser utilizado para representar o rodapé de um documento

## Atividade 17
**Resposta:**``<link>`` é utilizada para relacionar o documento HTML ao CSS externo. rel="stylesheet" informa que o arquivo é uma folha de estilos

## Atividade 16
**Resposta:** font-family define a família da fonte

## Atividade 17
**Resposta:** color define a cor do texto e text-align define o alinhamento

## Atividade 18
**Resposta:** Podemos selecionar dois ou mais elementos diferentes agrupando seus seletores separados usando vírgula no CSS (ex: h2, h3)

## Atividade 19
**Resposta:** O ponto (.) é utilizado no CSS para selecionar uma classe. O class no HTML é utilizado para associar o elemento à classe

## Atividade 20
**Resposta:** O símbolo cerquilha (#) é utilizado no CSS para selecionar um elemento pelo seu ID

## Atividade 21
**Resposta:** A propriedade width define a largura de um elemento. O valor auto na propriedade height ajusta automaticamente a altura

## Atividade 22
**Resposta:** A propriedade padding define o espaçamento interno de um elemento

## Atividade 23
**Resposta:** A propriedade margin define o espaçamento externo. A expressão margin: 0 auto serve para centralizar um elemento 

## Atividade 24
**Resposta:** A propriedade float permite que um elemento flutue. O valor left posiciona o elemento à esquerda

## Atividade 25
**Resposta:** A propriedade width define a largura, border-collapse unifica as bordas e border define a borda de um elemento

## Atividade 26
**Resposta:** A propriedade text-decoration: none, remove o sublinhado dos links

## Atividade 27
**Resposta:** O elemento ``<footer>`` representa o rodapé do documento
